🧪 Teste de AdSite

Ferramenta para testar anúncios e funcionalidade dos AdSites

📋 Método 1: Teste via Magnet Link

🎯 Como funciona: Este método simula um usuário clicando em um magnet link interceptado por JavaScript
⚠️ Pré-requisito:
  • • Você precisa ter um AdSite criado com banner configs
  • • O AdSite deve estar ativo no sistema
  • • Configure pelo menos 1 banner para Step 1 e Step 2

🚀 Método 2: Teste Direto com AdSite ID

🎯 Como funciona: Teste direto fornecendo o ID do AdSite e URL de destino

📋 Como Configurar Banner Configs

📊 No Painel Administrativo:

  1. Acesse "AdSites" → "Gerenciar AdSites"
  2. Encontre seu AdSite na lista
  3. Vá para "Advertisements" → "Banner Configs"
  4. Configure banners para Step 1 e Step 2
  5. Salve as configurações

🎯 Tipos de Banner:

  • 300x250: Banner médio (3 posições)
  • 728x90: Banner grande (2 posições)
  • 300x600: Banner vertical (1 posição)
✅ Dica: Você pode usar HTML simples nos banners, como: <div style="background: #3b82f6; color: white; padding: 20px; text-align: center; border-radius: 8px;">Seu Anúncio Aqui</div>
